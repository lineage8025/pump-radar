# TRADEABILITY_PREREG.md — 可交易性預登記

> 建立於 2026-08-05，**先於任何交易化研究的結果**。
> 本文件回答三件事：①「不做方向預測」這條紅線的精確界定（人類簽署）；
> ②什麼樣的結果才算「可以跑真實交易」；③每 2 小時一輪的自主迴圈要怎麼防 p-hacking。
>
> 位階：**低於** `docs/DETECTOR_PREREG.md`（偵測器參數與計分口徑的最高法律），
> **高於** `research/program.md`。本文件與 program.md 衝突時以本文件為準。
>
> 對 autoresearch agent **唯讀**。每輪運行的 SETUP 必須讀本檔，日誌必須引用 §1 的界定。

## 0. 為什麼需要這份文件

2026-08-05 起，autoresearch 迴圈改為**每 2 小時一輪**（12 輪／天），
且目標從「執行已登記的離線探針」擴大為「找出能真實交易的方向與策略」。

這兩件事合起來是危險的。一個被交代「找出賺錢策略」的 agent，一天醒來 12 次，
每次掃幾十個參數格位——**光靠運氣就一定會撞出「顯著為正」的結果**。
84 輪之後帳本裡若出現一筆漂亮的陽性，你分不出它是真的還是第 3,000 次擲骰子。

`research/program.md` 既有的凍結網格與 kill criteria 是為「一天 4 輪、單一方向」設計的，
撐不住這個強度。本文件補上三道原本沒有的防線：**§1 命題界定**（限制什麼題目可以問）、
**§3 假設預算與族系錯誤率**（限制可以問幾次）、**§4 holdout 封存**（限制在哪段資料上問）。

**設計立場**：本迴圈的成功定義不是「找到策略」，是**「快速產生可信的否定結論」**。
帳本裡一排誠實的 `weakens` 是成功；一筆未經 §3／§4 檢驗的 `supports` 是失敗。

## 1. 命題界定（人類簽署，2026-08-05）

`CLAUDE.md` 與 `research/program.md` §3 紅線 4 原文為「不做次根方向預測……
探針只准問振幅／分佈，不准問方向」。要設計交易策略必然要對淨報酬下主張，
故此處**精確化**該紅線。**精確化不是放寬**——受理範圍沒有變大，只是把邊界寫得可機械判定。

### 1.1 永久不受理（已證偽，不因任何新證據重開）

> 「給定 t 時刻的狀態，預測 t+1 根 15m K 棒的漲跌方向。」

DirProbe 92k 樣本實測 ~46%。任何形如「訊號後會漲還是會跌」「哪個方向勝率較高」
「多空哪邊期望值好」的題目**一律不受理**，不論包裝成什麼樣子。

### 1.2 受理範圍

- **振幅命題**：`(max(high) − min(low)) / close` 及其分位數、分桶差異。（Q1 系列）
- **路徑形狀命題**：振幅在時間上如何分佈——先走完再回頭，還是來回震盪。
- **方向中性結構的淨報酬**：同時對兩個方向持有對稱曝險的結構（雙向突破單、
  等差網格、對稱 trailing stop），其淨損益分佈。

### 1.3 判定工具：符號翻轉檢定（sign-flip test）

**任何題目在提出時，agent 必須先跑這個檢定並把結果寫進日誌。**

> 把所有標的的報酬序列整體乘以 −1（等價於把每根 K 棒的 open/close 對調、
> high/low 鏡射），重新推導本題的結論。
>
> - 結論**不變** → 這是振幅／路徑命題，**受理**。
> - 結論**消失或反轉** → 這是方向命題，**不受理**，記入日誌「誘惑清單」後放棄。

這條讓界定可機械判定，不靠語感。**它是硬性前置步驟，不是事後檢查。**

### 1.4 已用本檢定砍掉的題目（記錄在案，不得換皮重提）

| 題目 | 為何不受理 |
|---|---|
| 掃描不對稱 TP/SL（如 +1% 止盈 / −0.8% 止損）救活偵測器 | sign flip 後 `+a/−b` 變成 `−a/+b`，結論反轉。若 `a≠b`，獲利必然依賴「上漲比下跌更容易先發生」＝方向漂移主張；若 `a=b`，對稱 bracket 的期望值恆等於 0 減成本，必為負。**這條路數學上就不通，不是資料問題。** |
| 「A 級訊號適合做多、B 級適合觀望」之類的分級方向化 | 同上，方向命題。 |

## 2. 唯一的交易化入口，與它的統一命題

截至 2026-08-05，本專案累積的**已驗證**事實只有三條：

| # | 事實 | 證據 |
|---|---|---|
| 1 | `bbw_pct` 對後續振幅**有**區別力（24h p80 最低桶 vs 最高桶 +2.76pp，CI 不含 0） | Q1 / Q1′ / Q1″ / Q1‴，四輪 `supports`，Parkinson／GK／YZ 三估計量同向，兩個不重疊時期各自成立 |
| 2 | 15m 動能**方向**不可預測（~46%） | DirProbe 92k 樣本 |
| 3 | 無條件的高槓桿等差網格期望為負（出廠格位 T=30d 中位數 −100%、強平率 75.5%） | Q8，748,200 episodes，兩個 intrabar 路徑序皆負 |

事實 1 是**唯一**指向可交易性的入口。但它目前只是一個**統計**陳述，
從未被檢驗是否為**經濟**陳述。兩者的距離就是本迴圈要量的東西：

> ### 統一命題（本階段所有交易化研究的母題）
>
> **Q1 的振幅可預測性，扣掉交易成本後還剩下什麼？**
>
> 若振幅可預測且可變現，它應該同時養得起兩種相反的結構：
> 低 `bbw_pct` 桶（預測振幅小）→ **短伽瑪**（區間震盪吃格差）；
> 高 `bbw_pct` 桶（預測振幅大）→ **長伽瑪**（賭走勢走得夠遠）。
>
> **兩者都失敗，就是「Q1 統計顯著但經濟上不可變現」的直接證據**，
> 交易化路線整條終止——那是一個有價值的、可宣告的結論，不是失敗。

**關鍵洞察（決定了研究順序）**：Q1 只量了振幅的**大小** `(A+B)`，
從來沒量過振幅的**形狀**。而長伽瑪與短伽瑪誰可行，由形狀決定，不由大小決定。
所以第一步不是跑策略回測，是量形狀——見 `docs/RND_BACKLOG.md` 方向二 Phase 0。

## 3. 假設預算與族系錯誤率（防 12 輪／天的多重比較）

### 3.1 格位計數是強制申報項

每份研究日誌與每行 LEDGER 都必須申報本輪測試的**格位數**（cells）：

- LEDGER 的 `summary` 欄**必須以 `[cells=N]` 開頭**，N = 本輪實際計算了幾個
  「分桶 × T × 參數」組合。跑了就要數，包含跑出來覺得不好看沒寫進日誌的。
  （選這個寫法而非新增 TSV 欄位，是因為 guard step 的 append-only 檢查是 byte-prefix，
  改 header 會讓整份帳本判定為被竄改。）
- 研究日誌必須有一行：「本輪格位數 N，本方向累計格位數 M」。

**申報不實＝紅線違規**。這條沒有機器強制，只能靠帳本互相對照——
但格位數與探針程式碼的迴圈結構是對得起來的，事後可查。

### 3.2 宣告門檻隨累計格位收緊（Bonferroni）

任何「有效果」的宣告，其 bootstrap CI 必須用**族系調整後**的信心水準：

```
α_adjusted = 0.05 / M        （M = 該方向的累計格位數，不是本輪的）
```

- 方向二 Phase 0 的凍結網格是 6 桶 × 4 個 T = **24 格**，故 α = 0.05/24 ≈ 0.00208，
  即需要約 **99.79% CI 下界 > 0** 才准宣告 `supports`。
- 若同一方向跨多輪累積更多格位，M 只增不減，門檻只緊不鬆。
- **未達調整後門檻但達未調整門檻** → 一律記 `inconclusive`，日誌必須同時報兩個 CI，
  不得只報好看的那個。

Bonferroni 偏保守（格位間相關時過度懲罰），這是刻意的：
在無人監督、一天 12 輪的環境下，寧可漏掉真效應，也不要放進假效應。

### 3.3 經濟顯著性門檻（統計顯著不等於能賺）

**即使通過 §3.2，若效應量小於成本，仍判 `weakens`，不得進入下一 Phase。**

預登記成本模型（Binance USDT-M 永續，VIP0，無 BNB 折扣）：

| 項目 | 假設值 | 備註 |
|---|---|---|
| taker 手續費 | **0.05% / 單邊** | 保守取整；實際 0.045% |
| 滑價 | **0.02% / 單邊** | **暫定值**，須由方向三的 aggTrades 校準取代 |
| 單邊總成本 | **0.07%** | |
| **來回總成本** | **0.14%** | 進出各一次 |
| funding | **未計入** | 中性網格會累積方向性庫存，funding 是真實成本；任何短伽瑪結論須在限制段聲明此偏誤方向為「模擬比真實樂觀」 |

門檻：**可捕獲的效應量必須 > 2 × 來回總成本 = 0.28%**，
留 2 倍餘裕給模型誤差（滑價假設、掛單未必成交、容量限制）。

### 3.4 容量約束（預先寫死，避免研究出無法執行的策略）

單筆規模不得超過**該根 K 棒成交額的 0.1%**。任何策略若在此約束下的可部署資金
低於 1,000 USDT，即使期望為正也判定為不可交易，記 `weakens`。

## 4. Holdout 封存（最重要的一道防線）

### 4.1 三段切分

| 段 | 期間 | 用途 | agent 權限 |
|---|---|---|---|
| **in-sample** | 2023-01-01 ~ 2025-06-30（暖機 2022-12） | 所有探索、所有網格、所有迭代 | 可讀寫 |
| **holdout** | 2025-07-01 ~ 2026-06-30 | **封存**。只在某方向於 in-sample 通過 §3 全部門檻後，由**人類**跑一次確認 | **禁止讀取** |
| **forward** | 2026-07-01 起 | 真正的未來資料，隨時間累積 | **禁止讀取**，且 holdout 通過後才啟用 |

### 4.2 誠實聲明：holdout 不是完全乾淨的

2023-01 ~ 2026-06 這整段 K 線，Q1″（run5 延長窗口）與 Q8（Phase 1 網格回放）
**都已經整段跑過**。所以本文件的 holdout **不是從未被任何人看過的資料**。

它的乾淨程度僅限於：**本文件定義的新度量（§2 的「振幅形狀」及其衍生策略）
從未在任何窗口上被計算過**。Q1 看的是振幅大小，Q8 看的是等差網格損益，
兩者都沒碰過形狀統計量。

**這是無法消除的殘餘污染，照實記錄，不假裝它不存在。**
真正乾淨的只有 §4.1 的 forward 段，而它目前只有 1 個月、且會隨時間增長——
這就是為什麼 holdout 通過**不等於**可以上線，見 §5。

### 4.3 機器強制

workflow 的 guard step 檢查 agent 新增／修改的 `research/experiments/**` 檔案內容，
若出現指向封存期的資料抓取參數（`--end 2025-0[7-9]`、`--end 2025-1[0-2]`、`--end 2026-*`、
`--start 2025-0[7-9]` 等），視同紅線違規：自動 revert ＋ Discord 告警 ＋ job fail。

此檢查**只對新增行、只對 `experiments/` 目錄**生效——`research/log/` 與 `backlog.md`
會因為引述 Q1″／Q8 的歷史窗口而必然出現這些日期字串，不能一併攔。
**因此這道機器強制是嚇阻，不是保證**；真正的保證是日誌的資料窗口聲明（§6）與人類抽查。

## 5. 什麼叫「可以跑真實交易」（升級判準，預登記）

一個方向要被宣告為可交易，必須**依序**通過以下五關，缺一不可。
任一關未過即停在該關，不得跳關、不得回頭調參數再試。

| 關 | 條件 | 誰執行 |
|---|---|---|
| **1. in-sample 統計** | 效應量的 bootstrap CI 下界 > 0，信心水準經 §3.2 族系調整；逐 ISO 週 block bootstrap（episode 重疊使樣本非獨立） | agent |
| **2. in-sample 經濟** | 扣 §3.3 成本後的每筆淨期望 > 0.28%，且滿足 §3.4 容量約束 | agent |
| **3. 穩健性** | 效應在**兩個不重疊子期**各自成立（比照 program.md §4.2 第 3 條）；且對 intrabar 路徑假設不敏感（雙序同號，比照 Q8 教訓） | agent |
| **4. holdout 確認** | 在 §4.1 封存段上**單次**跑出符合關 1／2 的結果，且點估計與 in-sample 的差距在預登記容忍範圍內（|Δ| ≤ in-sample 效應量的 50%） | **人類**（agent 無權讀取封存段） |
| **5. forward 預登記** | 另寫一份策略預登記文件，鎖死進出場、風控、部位大小與計分口徑，**禁止沿用 `detector.py` 的任何 PARAMS**，開跑 paper trading 累積 ≥200 筆 | **人類** |

**通過關 5 之前，一毛錢都不上。** 這與 `docs/DETECTOR_PREREG.md` §「升級判準」
是兩條獨立的路徑：偵測器的升級判準管的是偵測器本身，本文件管的是新的交易化方向，
**兩者的證據不得互相借用**。

### 5.1 agent 的權限上限

agent **最多只能做到關 3**，且結論只能是以下三種之一：
`weakens`（未過判準，方向淘汰）、`inconclusive`（樣本不足或不穩健）、
`supports`（過了關 1~3）。

**`supports` 不等於採納。** 過了關 3 的方向，agent 的正確行為是開一份
`Frontier Proposal:` issue 附全套證據**交人類裁決**，
然後在 backlog 標記為「待人類執行關 4」——**不得自行宣告策略可用，
不得自行進入下一階段，不得在 Discord 摘要裡使用「可以交易」「找到 edge」這類措辭。**

## 6. 每份研究日誌的強制聲明段

除 `program.md` §8 既有要求外，本階段每份日誌**必須**額外包含：

1. **命題界定聲明**：本輪題目通過 §1.3 sign-flip 檢定的推導過程（一段話即可）。
2. **資料窗口聲明**：實際使用的起訖日期與標的，明確寫出「未觸碰 §4.1 封存段」。
3. **格位申報**：本輪格位數 N、本方向累計 M、據此計算的 α_adjusted。
4. **雙 CI 並報**：未調整 CI 與族系調整後 CI 兩者都報。
5. **成本後效應量**：扣 §3.3 成本後還剩多少，對照 0.28% 門檻。

缺任何一項，該輪結論一律降級為 `inconclusive`。
