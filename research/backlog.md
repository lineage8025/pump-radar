- **Q16 `audit` closed（2026-08-07 run 22，主問題結案；承接缺口見下）** —
  **Q10 頭條數字 `cap = ΔR × E[A+B]` 是不是它自稱的「上界」？** 本輪格位數 0，
  方向二累計 M 維持 24。補的是 run 18（Q14）自己在本檔寫下的缺口——
  「稽核只保證**算得對**，不保證**度量選得對**」。
  - **疑點（純算術）**：預登記式是**平均數的乘積**，逐 episode 的對應量是
    `E[ΔR_i·amp_i] = E[ΔR]·E[amp] + Cov(ΔR_i, amp_i)`，
    **`Cov` 這一項 run8/13/18 從未計算過**。
  - **第一步（表象）**：`Cov > 0` **24/24 格**，量級大於乘積項本身；改用配對式後
    頭條格位 0.0886% → **0.2157%（2.43 倍）**，且 9 個原本為負的格位符號被翻正。
  - **第二步（證偽自己，決定性）**：純 iid H0 合成資料（**定義上零可捕獲結構**，
    1,000 episodes × 200 flips × 4 個 T）下，`ΔR` 與 0 無法區分（`|z| ≤ 1.63`，
    順帶第三次重現 run8 §7.1 的 `iid` 對照），**但 `cov` 四個 T 全正、
    `corr(ΔR,amp) = +0.2413/+0.2662/+0.2842/+0.3013`、`cap_pair` 四個 T 全正**。
    機制是純幾何：`ΔR_i` 對符號抽取中心化，**但 `amp_i` 本身也是符號序列的函數**
    （固定 `|r_i|` 時符號一致⇒range 大、符號來回⇒range 小），
    ⇒ 翻轉系綜**內部** `R` 與 `amp` 已正相關 ⇒ `E[ΔR_i·amp_i] > 0` 在 H0 下成立。
    **⇒ 配對式是無效統計量，第一步的表象是幾何偽影，不是額外可捕獲報酬。**
  - **第三步（替預登記補正當性）**：兩者的 H0 偏差差 `n` 倍——
    `E[cap_pair] = Cov`（頭條格位 0.1271pp），`E[cap_prod] = Cov/n`
    （n=1335 ⇒ 9.5e-5pp，比點估計小四個數量級）。
    **`docs/RND_BACKLOG.md` 方向二寫死的乘積式是唯一 H0 置中的候選，預登記選對了
    ——但預登記文件與 run8/13/18 都沒寫下理由，本輪補上。**
  - **判定重推**：三個聚合版本的全網格最大值 **0.0886%（乘積式，唯一有效）／
    0.2157%（配對式，無效）／0.1429%（指示性去偏，非宣告）全部 < 0.28%**
    ⇒ **Q10 的 `weakens`（結局②）不動搖。** 且對「真實 H0 偏差比 iid 小」這條反駁
    免疫：要越過 0.28% 需殘差放大 3.5 倍＝真實 H0 偏差得是負值，幾何上不可能。
  - **⚠ 新記錄的精度限定（先前無人記載，引用時必須一起講）**：run8 §10 反駁 3 的
    「0.0886% < 0.10% < 0.20% < 0.28%——四個門檻版本全部打不過」**是聚合式相依的**。
    配對式 0.2157% 越過 0.20% 與 0.10%；去偏版 0.1429% 越過 0.10%。
    **「對成本模型不確定性免疫」成立是因為聚合式選對了，不是因為餘裕大。**
    預登記門檻 0.28% 仍安全。
  - **附帶**：`cap_prod` 24 格與 n 對 run8 `grid.tsv` **逐位元重現**（`max|Δ|=1.11e-16`pp、
    n 24/24 相符）；未調整／調整後 CI 上界最大 +0.1432%／+0.1830%，與 run8
    （+0.1443%／+0.1838%）、run13（0.1797~0.1889%）、run18（≤0.1906%）一致
    ⇒ **run8 CI 的第四次獨立重現。**
  - **本輪驗不到的（＝承接缺口，見下一條）**：H0 安慰劑組是 iid、close-only、
    無波動聚集無厚尾，**不是真實資料的校準虛無分佈**。真實 `cov/E[amp]` 是
    iid-H0 的 **0.95~2.26 倍**，這個倍數究竟是「真實超額」還是「波動聚集把 H0
