### 0.1 為什麼在 focus=Q10 之下做這件事（決策留痕）

Q10 已於 run 8 結案（`weakens`，結局②），並已於 run 13 由 Q13 做過一次獨立復算稽核。
**run 13 自己的「最強反駁」點名了它沒能驗到的那一塊**，並寫進 `backlog.md` 與
run13 日誌 §5 限制 1、§7、§10.3：

> `R_flip` 需要 1m 逐根符號翻轉重建 200 次，用 15m 資料在原理上就做不到。
> 換句話說 `ΔR = R_act − R_flip` **只有被減數被獨立驗證了**。
> ……**`ε≠+1` 分支仍只有 run 8 自己的 self-test 背書**。
> 若人類認為值得，唯一乾淨的作法是重抓 1m 資料、由第二份獨立實作重跑翻轉——
> 那是一整輪的工作量。

本輪在 focus=`Q10` 之下的選項與取捨：

| 選項 | 判斷 |

  且被前一輪自己指名為唯一剩餘缺口的事** |
| **`R_flip` 獨立復驗（本輪）** | ✓ `audit` 車道定義（「只覆核既有主張，不提新主張」）；
  cells=0；不改網格、不碰封存段；正好補上 Q13 限制段 1 的那一塊 |

**必須誠實揭露的一點**：run 13 把「是否值得重驗 `R_flip`」列為**待人類裁決**項

**這是我的解讀，不是人類的明示裁決**——若解讀有誤，代價已被限制在：
本輪 `[cells=0]`、不新增任何假設、不改變任何判定，最壞情況是一輪的算力。

## 1. 命題界定聲明（`docs/TRADEABILITY_PREREG.md` §1.3）

**本輪不提出任何新命題，故 §1.3 的符號翻轉檢定不適用於「受理與否」的判定**
（比照 run 10/11/13 對 Q11/Q13 的處理）。被稽核的命題是 run 8 已登記並已通過
§1.3 的 Q10 度量 `R = max(A,B)/(A+B)`（推導見 `research/log/2026-08-05.md` §1：
報酬序列整體乘 −1 ⇒ `A↔B` 互換 ⇒ `max(A,B)` 與 `A+B` 皆不變 ⇒ R 不變）。

**但本輪有一個 run 13 沒有的性質，必須點出**：本輪稽核的對象**就是符號翻轉機制本身**。
因此 §1.3 的那條不變性在本輪不只是「界定用的推導」，它同時是一個**可機械驗證的
判準**——把 ε 全部設成 −1（＝整段鏡射）後，R 必須逐位元不變。
這正是 §5 Part 1(b) 的檢定項，也是 run 13 明說沒能驗到的 `ε≠+1` 分支的第一個直接檢定。

## 4. 稽核的獨立性協定（先寫死，避免事後放水）

「獨立實作」若只是把原探針抄一遍，稽核價值為零。本輪的獨立性由以下三條保證：

1. **由規格實作，不由程式碼實作**：本輪的翻轉／路徑重建程式碼**依
   `research/log/2026-08-05.md` §4 的四條操作化決定（文字規格）從頭撰寫**，
   撰寫期間**刻意不閱讀** `2026-08-05_q10_shape_capturable_trend.py` 的翻轉實作段落。
   只在（i）確認 `samples.tsv` 欄位語意、（ii）若結果不吻合需要歸因時才回頭讀原始碼，
   **且若發生（ii）必須照實記錄在 §7 的執行註記**。
2. **不同的數值路徑**：全程 **float64**（run 8 的翻轉批次用 float32，
   其 self-test 7 只量到 `<1e-4` 的差異，本輪直接用 float64 獨立檢查該近似有無系統性偏移）；
   RNG 用**不同的 bit generator 與 seed**（run 8 未在日誌宣告其 seed，本輪用
   PCG64 與 Philox 各跑一組）。
3. **暴力對拍參考實作**：向量化實作之外，另寫一份逐根 for-loop 的樸素實作，
   在隨機抽樣的錨點上逐位元對拍（Q8 的教訓：**合成測試不能取代對拍參考實作**）。

## 5. 方法（四個 Part，**判準在下一節先寫死**）

**Part 1 — 確定性檢定（不含亂數，全部 9,010 錨點 × 4 個 T）**

- (a) `ε ≡ +1`：重建出的 `A/B/R` 必須等於**直接由 1m 原始 high/low 取極值**算出的值。
  （驗證我自己的重建正確，同時獨立複驗 run 8 §4 決定 2 的執行期硬驗證。）
- (b) `ε ≡ −1`（整段鏡射）：`A_flip` 與 `B_flip` 必須與未翻轉版**互換**，
  且 `R` 在**對數空間**逐位元不變。**這是 `ε≠+1` 分支的第一個直接檢定。**
- (c) `ε` 為固定樣式（前半 +1／後半 −1、以及奇偶交替）：與樸素 for-loop 參考實作逐位元對拍
  （隨機抽 200 個錨點，避免 O(n) 的 Python 迴圈跑滿全量）。

**Part 2 — 蒙地卡羅復驗（本輪主體）**

用獨立實作重跑 200 次隨機符號翻轉，得到自己的 `R_flip`、`ΔR`，
與 `2026-08-05_q10_shape_grid.tsv` 的 24 格逐格比較。跑 **≥3 組獨立 seed**
（含至少一組 Philox）以估計蒙地卡羅標準誤。

**Part 3 — RNG 與精度的偏誤檢查**

- `ε` 抽樣的經驗均值與 ±1 比例（檢查 run13 反駁點名的「ε 抽樣有偏」）。
- float32 vs float64 在同一組 `ε` 下的 `R` 差異分佈（檢查「float32 批次在極端值上失準」）。

**Part 4 — 判定重推（決定性的一段）**

用**我自己的** `R_flip` 重算 24 格 `ΔR`、逐 ISO 週 block bootstrap（自寫，boot=20,000，
`α_adj = 0.05/24`）、可捕獲報酬上界 `cap = ΔR × E[A+B]`，
檢查 Q10 的三個決定性宣告是否成立。

## 6. 預先寫死的判準（**先於任何結果**）

| Part | 通過條件 | 未通過的處置 |
|---|---|---|
| 1(a) | 全 9,010 × 4 誤差 `<1e-9` | 先查我自己的實作；排除後即為 run 8 的缺陷，照實記錄並升級為 `error` 等級發現 |
| 1(b) | 對數空間 `\|R_flip(−1) − R_act\|` 全部 `<1e-12`；`A↔B` 互換成立 | 同上 |
| 1(c) | 向量化 vs 樸素實作逐位元 `<1e-12` | 同上 |
| 2 | 逐格 `\|R_flip_mine − R_flip_run8\|` 落在 **4 × se_MC** 內（`se_MC` 由本輪多 seed 估計），**且 24 格的差值無一致方向的系統性偏移**（符號檢定 24 格） | 記為**不吻合**，量化偏移大小與方向，**交人類裁決**，不自行修訂 Q10 |
| 3 | `ε` 均值 `\|·\| < 4/√(抽樣數)`；float32/64 的 `R` 差異 `<1e-4`（run 8 self-test 7 的宣稱） | 照實記錄偏誤方向與量級 |
| 4 | 調整後顯著格數 **＝1 格且為 `[0.10,0.25)×24h`**；`cap` 點估計最大值 ≈ **+0.0886%**；`cap` 調整後 CI 上界最大值 **< 0.20%** | 任一項不成立即記為**判定受影響**，寫明新舊數字，**交人類裁決**（`TRADEABILITY_PREREG.md` §5.1：agent 不得自行改動已結案裁決） |

**事先聲明兩件事，避免事後被結果牽著走**：

1. **本輪不可能把 Q10 從 `weakens` 翻成別的東西。** 稽核的方向性只有兩種：
   「復現 ⇒ 裁決更可信」或「不復現 ⇒ 記錄異常交人類」。
   即使我的 `R_flip` 系統性偏低（會讓 `ΔR` 變大），§6 判準 4 的處置仍是**交人類**，
   不是由我改寫 Q10。
2. **`boot=20,000` 是預登記值**，本輪照用；比照 run 13 §5 限制 6，
   不用更高精度的版本取代任何已宣告的 CI。
