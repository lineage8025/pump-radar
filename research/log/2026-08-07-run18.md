## 5. 方法（四個 Part，**判準在下一節先寫死**）

**Part 1 — 確定性檢定（不含亂數，全部 9,010 錨點 × 4 個 T）**

- (a) `ε ≡ +1`：重建出的 `A/B/R` 必須等於**直接由 1m 原始 high/low 取極值**算出的值。
  （驗證我自己的重建正確，同時獨立複驗 run 8 §4 決定 2 的執行期硬驗證。）
- (b) `ε ≡ −1`（整段鏡射）：`A_flip` 與 `B_flip` 必須與未翻轉版**互換**，
  且 `R` 在**對數空間**逐位元不變。**這是 `ε≠+1` 分支的第一個直接檢定。**
- (c) `ε` 為固定樣式（前半 +1／後半 −1、以及奇偶交替）：與樸素 for-loop 參考實作逐位元對拍
  （隨機抽 200 個錨點，避免 O(n) 的 Python 迴圈跑滿全量）。

**Part 2 — 蒙地卡羅復驗（本輪主體）**

用獨立實作重跑 200 次隨機符號翻轉，得到自己的 `R_flip`、`ΔR`，
與 `2026-08-05_q10_shape_grid.tsv` 的 24 格逐格比較。跑 **≥3 組獨立 seed**
（含至少一組 Philox）以估計蒙地卡羅標準誤。

**Part 3 — RNG 與精度的偏誤檢查**

- `ε` 抽樣的經驗均值與 ±1 比例（檢查 run13 反駁點名的「ε 抽樣有偏」）。
- float32 vs float64 在同一組 `ε` 下的 `R` 差異分佈（檢查「float32 批次在極端值上失準」）。

**Part 4 — 判定重推（決定性的一段）**

用**我自己的** `R_flip` 重算 24 格 `ΔR`、逐 ISO 週 block bootstrap（自寫，boot=20,000，
`α_adj = 0.05/24`）、可捕獲報酬上界 `cap = ΔR × E[A+B]`，
檢查 Q10 的三個決定性宣告是否成立。

| 檢定項 | 全標的 max\|Δ\| | 預登記門檻 | 判定 |
|---|---|---|---|
| (a) `ε≡+1` 重建 A/B vs 直接由 1m 原始 high/low 取極值 | **1.597e-14** | `<1e-9` | ✔ |
| — 我的 `R_act` vs run 8 `samples.tsv` | **1.864e-12** | （非預登記項，附帶） | ✔ |
| — 我的 `amp` vs run 8 `samples.tsv` | **1.643e-14** | 同上 | ✔ |
| (b) `ε≡−1` 對數空間 R 不變性 | **0.000e+00** | `<1e-12` | ✔ |
| (b) `ε≡−1` 對數空間 `A↔B` 互換 | **0.000e+00** | `<1e-12` | ✔ |
| (c) 向量化 vs 樸素 for-loop（`half`／`alt`／`rand` 三種 ε 樣式） | **0.000e+00** / **0.000e+00** / **0.000e+00** | `<1e-12` | ✔ |

**(b) 是本輪的核心**：run 13 §5 限制 1 明說「`ε≠+1` 分支仍只有 run 8 自己的 self-test 背書」。
把 ε 全部設成 −1 就是把整段路徑鏡射，依 `TRADEABILITY_PREREG.md` §1.3 的推導，
對數空間的 R 必須**恆等**。實測是**逐位元 0**，不是「小於某個容差」——
因為 `A↔B` 互換後 `max` 與 `+` 兩個運算逐位元對稱。
這同時是 §1.3 那條界定在真實資料上的機器驗證。

**(c) 的意義**（Q8 教訓：合成測試不能取代對拍參考實作）：樸素版是純 Python 逐根迴圈、
逐步維護 `cum`／`mx`／`mn`，與向量化版的 `cumsum` ＋ `maximum.accumulate` 在**運算次序上完全不同**，
浮點捨入本可不同——實測仍是逐位元相等。
